Welcome! This is the first post on this blog. It's built with **Next.js**, written in **MDX**
(so you can drop React components straight into a post), and deployed on **Vercel**.

## What this blog can do

- Rich posts written in Markdown/MDX, with syntax-highlighted code blocks
- Embedded audio, like a short clip below
- Full-text search
- Comments and likes for logged-in readers
- A newsletter you can subscribe to
