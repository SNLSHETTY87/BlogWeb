Every post lives in `content/posts/` as an `.mdx` file with frontmatter up top:

```md
---
title: "My Post"
date: "2026-07-10"
excerpt: "A short summary shown on the home page."
tags: ["guide"]
cover: "/images/my-cover.svg"
---
```

## Adding images

Upload an image from `/admin/upload` (once you're logged in as the site owner) and paste
the returned URL into the post as a normal Markdown image:

```md
![A description](https://your-blob-url/image.png)
```

## Adding audio or music

Use the built-in `AudioPlayer` component right inside the MDX body:

```mdx
<AudioPlayer src="https://your-blob-url/track.mp3" title="Track title" />
```

That's it — no special build step, just write and commit.
